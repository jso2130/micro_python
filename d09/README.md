# D9 — 깃발·% 연산·논리 연산·인터럽트·PWM

| 파일 | 내용 |
|---|---|
| c0, c1 | 깃발 하나로 LED 두 개 |
| c2d, c2e | 나눗셈 원리와 % |
| c2, c2b, c2c | `% 100`·`% 500` 독립 운영, sleep 오차, 느린 함수 |
| c3, c3b, c3c | not · AND OR XOR NOT · XOR 토글 |
| c4 | 1ms 타이머 인터럽트 (메인이 센다) |
| c4b | c4 에 느린 일(300ms)을 넣으면 시간이 밀린다 |
| c4c | 인터럽트가 세고 깃발만 세운다 (10·100·500·1000ms) |
| c4d | c4c 에 같은 느린 일을 넣어도 시간이 밀리지 않는다 |
| c5~c8 | PWM duty · 페이드 · 범위 · 감성 조명 |
