# D9-2 — 현업 방식 인터럽트: 인터럽트가 세고 깃발은 시간 단위마다

| 파일 | 내용 |
|---|---|
| c4 | 복습: 1ms 타이머 인터럽트 (메인이 센다) |
| c4b | c4 에 느린 일(300ms)을 넣으면 1초가 약 1.6초로 밀린다 |
| c4c | 인터럽트가 세고 10·100·500·1000ms 깃발을 따로 세운다. 메인은 깃발을 내리고 나서 일한다 |
| c4d | c4c 에 같은 느린 일을 넣어도 시계가 밀리지 않는다 (1초 간격 약 1000ms) |

플래시(GPIO4)는 매우 밝으니 직시하지 마세요. 멈추기는 Ctrl+C, 오류가 난 뒤에는 Ctrl+D 로 보드를 재시작합니다.
