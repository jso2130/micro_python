# D10 — 버튼 입력과 % 분기 일반화

보드의 **IO0 버튼**(GPIO0, 누르면 0)을 입력으로 씁니다. 부팅 중에는 누르지 마세요.

| 파일 | 내용 |
|---|---|
| b1 | 버튼 읽기 — 눌림/뗌을 터미널에 출력 |
| b2 | 누르는 동안 플래시 켜기 |
| b3 | 1ms 타이머 + 10ms 태스크로 누를 때마다 플래시 토글, 빨간 LED는 계속 깜빡임 |
| b2b | 일부러 `sleep` 방식으로 읽어 누름을 놓치는 장면 |
| g1~g5 | 오락실: 손전등·디머/호흡등·반응속도 게임·비밀 금고·합체 (자세한 조작법은 `README_오락실.md`) |
| d1 | 할 일 5개를 본문에 풀어 쓰면 (지저분한 버전) |
| d2 | `elif` 함정 — 1000ms 순간에 500ms 할 일이 빠진다 |
| d3 | 주기와 할 일을 표(`TASKS`)로 정리하고 `for` 로 돌린다 |
| d4 | 카운터를 한 바퀴(`CYCLE`)마다 0으로 되돌린다 |
| d5 | 가짜 센서를 1000ms 마다 읽어 출력 |
| d6 | 가짜 센서 값으로 플래시 밝기(PWM)를 바꾸는 종합 |

가짜 센서는 외부 부품 없이 계산으로 만든 값(0~100)입니다.
플래시(GPIO4)는 매우 밝으니 직시하지 마세요.
