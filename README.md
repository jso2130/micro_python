## 일자별 폴더

폴더 이름에 그날 배우는 내용이 들어 있습니다.

| 폴더 | 강의 내용 |
|---|---|
| `d09_타이머인터럽트_PWM` | 깃발·% 연산·논리 연산 → 1ms 타이머 인터럽트 → PWM 밝기·페이드·감성 조명 |
| `d09-2_현업방식_인터럽트깃발` | 시계를 인터럽트가 세고 깃발은 시간 단위마다 — 느린 일에도 시계가 안 밀리는 현업 방식 |
| `d10_버튼입력_분기일반화` | IO0 버튼 입력 → 할 일이 늘어도 지저분하지 않게(% 분기·`TASKS` 표) → 가짜 센서 |

## 하드웨어

- 플래시 LED **GPIO4** (1=켜짐, PWM 가능) · **매우 밝다, 직시 금지**
- 빨간 LED **GPIO33** (0=켜짐, 거꾸로)
- **IO0 버튼** GPIO0 (누르면 0) · 부팅 중에는 누르지 말 것
