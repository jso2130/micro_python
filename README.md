## 일자별 폴더

폴더 이름에 그날 배우는 내용이 들어 있습니다.

| 폴더 | 강의 내용 |
|---|---|
| `d09_타이머인터럽트` | 깃발·% 연산·논리 연산 → 1ms 타이머 인터럽트 |
| `d10_현업방식인터럽트_PWM` | 시계를 인터럽트가 세고 깃발은 시간 단위마다(현업 방식) → 심화 문제 → PWM 밝기·페이드·감성 조명 |

## 하드웨어

- 플래시 LED **GPIO4** (1=켜짐, PWM 가능) · **매우 밝다, 직시 금지**
- 빨간 LED **GPIO33** (0=켜짐, 거꾸로)
