# D10 버튼 오락실 — 실습 코드 안내

입력은 **IO0 버튼 하나**(GPIO0, 누르면 0), 출력은 **플래시**(GPIO4, PWM 0~1023)와 **빨간 LED**(GPIO33, 0 이 켜짐). 외부 부품 없음.
모든 코드는 `타이머 인터럽트(깃발만) + 메인이 깃발 확인 후 일하기` 구조(D9-2 와 같다). 끝내려면 Thonny 의 정지(Ctrl+C).

## 파일별 설명과 조작법

| 파일 | 한 줄 설명 | 조작법 |
|---|---|---|
| `b2b_sleep_misses_button.py` | 일부러 sleep 으로 깜빡이며 버튼을 읽어, 짧은 누름을 놓치는 걸 체험 | 짧게 10번 눌러 보고 화면에 찍힌 횟수와 비교 |
| `g1_flashlight.py` | 스마트 손전등: 꺼짐→약→중→강→꺼짐 | 누를 때마다 한 단계 |
| `g2_dimmer_breath.py` | 디머+호흡등 | 짧게(0.5초 미만) = 켜짐/꺼짐, 길게 = 누르는 동안 서서히 밝아지거나 어두워짐(번갈아), 놓으면 고정 |
| `g3_reaction_game.py` | 반응속도 게임 | 누르면 빨간 LED(준비) → 1~4초 랜덤 대기 → 플래시 켜짐 → 최대한 빨리 누르기. 일찍 누르면 반칙(빨간 LED 빠르게 깜빡). 최고 기록 갱신 표시 |
| `g4_secret_vault.py` | 비밀 금고: 짧·짧·긴 패턴 | 패턴이 맞으면 플래시가 서서히 켜짐(열림), 틀리면 빨간 LED 경고. 패턴은 `PATTERN` 리스트만 바꾸면 된다 |
| `g5_arcade.py` | 오락실 합체 메뉴 | 메뉴에서 클릭 = 다음 모드(빨간 LED 깜빡임 횟수 1~4 = 손전등·호흡등·반응속도·금고), 1초 꾹 = 시작, 게임 중 3초 꾹 = 메뉴로 |

## 주의
- **플래시를 눈으로 직접 보지 말 것**(매우 밝다). 책상이나 벽을 비추게 놓는다.
- **IO0 는 부팅 스트랩 핀**: 보드 전원을 켜거나 리셋하는 중에는 버튼을 누르지 않는다. 부팅이 끝난 뒤에 누른다.
- 짧은 누름 판정은 10ms 마다 확인하므로 그보다 짧은 "톡"은 놓칠 수 있다(보통 손가락은 50ms 이상).
- g5 에서 호흡등은 3초 이상 누르면 메뉴로 나가므로, 한 번에 3초 넘게 누르지 않는다.
- 파일 하나로 완결되어 있으니, 실행할 파일 하나만 Thonny 에서 열어 실행한다.
