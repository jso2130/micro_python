# D9 — 타이머 인터럽트와 PWM: 깃발·% 연산·논리 연산·인터럽트·PWM 감성 조명

| 파일 | 내용 |
|---|---|
| c0, c1 | 깃발 하나로 LED 두 개 |
| c2d, c2e | 나눗셈 원리와 % |
| c2, c2b, c2c | `% 100`·`% 500` 독립 운영, sleep 오차, 느린 함수 |
| c3, c3b, c3c | not · AND OR XOR NOT · XOR 토글 |
| c4 | 1ms 타이머 인터럽트 (메인이 센다) — 이어지는 내용은 `d09-2_현업방식_인터럽트깃발` |
| c5~c8 | PWM duty · 페이드 · 범위 · 감성 조명 |
