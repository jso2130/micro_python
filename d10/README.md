# D10 — 할 일이 늘어도 지저분하지 않게: % 분기로 일반화

| 파일 | 내용 |
|---|---|
| d1 | 할 일 5개를 본문에 풀어 쓰면 (지저분한 버전) |
| d2 | `elif` 함정 — 1000ms 순간에 500ms 할 일이 빠진다 |
| d3 | 주기와 할 일을 표(`TASKS`)로 정리하고 `for` 로 돌린다 |
| d4 | 카운터를 한 바퀴(`CYCLE`)마다 0으로 되돌린다 |
| d5 | 가짜 센서를 1000ms 마다 읽어 출력 |
| d6 | 가짜 센서 값으로 플래시 밝기(PWM)를 바꾸는 종합 |

가짜 센서는 외부 부품 없이 계산으로 만든 값(0~100)입니다.
